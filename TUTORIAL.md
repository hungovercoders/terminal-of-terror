# Building Terminal of Terror

The tutorial that used to live here has grown into a course: **Count Cathode's Night School**, 31 nights that build Terminal of Terror from an empty folder to a released Go CLI, one lesson a night.

📺 *"Thirty-one nights. Bring a blanket."*

**Start here: [docs/course/README.md](docs/course/README.md)**

- Nights 1 to 14 are build-along: type the code, run it, see it work.
- Nights 15 to 31 teach the ideas behind the finished program and point at the files in this repository.
- Every night ends with an exercise and a Go fact.

The finished code is in this repository; the course explains how it got that way.
