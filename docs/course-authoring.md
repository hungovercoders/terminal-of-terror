# Writing the course

- `course/README.md` is the index and `course/night-<NN>.md` is one lesson. The index is also the website's Night
  School page, so write it for learners.
- Nights 1-14 are build-along and their code must compile as written. Nights 15-31 quote the repository's files,
  so update a lesson when you change code it shows.
- Link to repository files with `../path/to/file.go`; the website rewrites those links to GitHub.
- Every lesson keeps the same sections: intro quote, "Tonight you'll learn", "Where we are", "Run it", "Try it",
  "💀 Terrifying fact", "🕯️ Before dawn", sign-off quote, navigation links.
- TUTORIAL.md only points at the course.
