Channel 13 · The small print

Privacy

📺 "I watch a great many things from beyond the static. You are not one of them."

What this site collects

Nothing of its own. There are no accounts, no forms, no cookies and no analytics or tracking scripts. The site is a set of static pages whose only scripts are its own site.js and, on the Night School lessons, a code highlighter from cdnjs. Its Content-Security-Policy allows scripts from those two sources alone and none inline, which rules out an injected snippet; what those scripts do is a matter of what the site includes, which is why this page is kept in step with it.

Hosting

The pages are served by Cloudflare. Like any host, Cloudflare processes your IP address and browser details to deliver each page, and it keeps aggregate traffic statistics (how many requests, from which countries, with which status codes) and short-lived request logs that the maintainers use to keep the site working. Cloudflare's handling of that data is described in its privacy policy. Nothing from it is combined with anything else or used to identify you.

Other services the pages talk to

  • GitHub. The home page asks GitHub's public API which release is newest so the install instructions can name it, and links throughout go to the repository. GitHub has its own privacy statement.
  • cdnjs. The Night School lessons load their code highlighter from cdnjs, a Cloudflare service; the files are pinned by hash.
  • Fonts are served from this site, not from a font service.

The program itself

terminal-of-terror makes no network requests. Your quiz scores, captured monsters and badges live in one JSON file in your own config directory (terminal-of-terror crypt prints where), and crypt reset deletes it.
